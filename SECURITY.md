# Security and private data

Report security vulnerabilities or accidental credential exposure through
[GitHub private vulnerability reporting](https://github.com/treister/market-tv-studio/security/advisories/new).
Do not include credentials, tokens, raw provider replies, studio databases or
private employee/conversation content in public issues.

For ordinary bugs, use the issue forms and include only the release version, OS,
intended action, observed behaviour and an optional scrubbed incident identifier.
No response-time or remediation guarantee is implied by this experimental project.

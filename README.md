# Market TV Studio

**Run a tiny television studio full of AI personalities.**

Hire a cast. Brief your producer. Watch the show. Help the next episode get better.

Market TV Studio is an experimental Mac app exploring a studio-management game
with AI employees. Rhea is your channel manager and main contact. The intended
experience is a creative team that researches, writes, reviews and presents
programmes, with personalities and choices that matter across episodes.
The first format is a finance newsroom with sourced analysis and visual explainers.

## Project Status

Public playtest home, opened November 23, 2026.
**No downloadable build is available yet.** Follow this repository’s Releases for a
verified playtest build and the exact supported setup when it is ready. The application is a
pre-alpha under active development; current work focuses on reliable complete
episodes, expressive two-presenter acting and independent first-time setup.

Voiced scene studies, source graphics, hiring and production/review workflows
exist. Complete novice setup, two fresh accepted programmes and presented
air/replay/recovery remain release gates. A working development studio is not
proof that a new download can produce a show without help.

## Who The First Playtest Is For

Creative tinkerers, agent enthusiasts and simulation players willing to test an
unfinished experience and report what happens. We want to learn whether the cast
is enjoyable, the owner's decisions feel meaningful and a complete episode can
be produced without developer rescue.

The initial supported platform is still being validated. Current builds target
macOS27.0 on Apple Silicon. Intel Macs and older macOS versions are not verified.
Release notes will state the exact tested requirements before a download appears.

## Accounts, Cost And Data

New studios start with Rhea alone; you hire colleagues through the app. Production
uses your configured provider accounts and can incur real charges. The release
will document required accounts, source/runtime setup, measured episode costs
and spending controls. Finance can act within the authority you choose.

The current factual source route uses IB Gateway and an external IBKR MCP source;
portable guided setup still needs verification. Publicly watching an eventual
sample recording will be separate from generating a new programme.

Private studios, credentials and paid assets are not included in this repository.
Do not post keys, raw logs, provider payloads or studio databases in public issues.
The financial format is experimental entertainment; source context and freshness
matter. Simulated audience figures do not represent actual viewers or revenue.

## What We Want Feedback On

- Could you get from first launch to watching a complete episode?
- Do the presenters sound and act like different people who are listening?
- Do the charts explain something useful, and can you read them?
- Did your feedback visibly change the next revision?
- What made you want to return, or stop playing?

When reporting a failure, include the release version, macOS version, the action
you expected to work and what you saw. Use the app's scrubbed incident export when
available. Use [private vulnerability reporting](https://github.com/treister/market-tv-studio/security/advisories/new)
for security or credential-exposure reports. See [known issues](KNOWN_ISSUES.md)
for release blockers. This public repository hosts download announcements and
feedback; the application source code remains private. Any future binary will
include its licence/terms and third-party notices.

Later plans include social programmes, employee discoveries and optional sharing
of approved moments. These follow a show engine that works. Advertising is later
and optional; sharing or referrals will not be required to play.

# Market TV Studio

An experimental AI television studio for Mac. The aim is to hire AI employees
who research, write and present shows. Financial news is the first format.

**[Download the Mac app](https://github.com/treister/market-tv-studio/releases/download/v0.1.0-prealpha.1/Market-TV-Studio-0.1.0-prealpha.1-macOS-arm64.zip)** · Apple Silicon · macOS27.0

Pre-alpha. Production reliability, presenter animation and first-time setup are unfinished.

This repository hosts release announcements and feedback. Application source
code remains private. Production uses your provider accounts and costs money.
Current development builds target macOS27.0 on Apple Silicon; other systems
are unverified.
